# Full-Stack Expense Tracker

A learning project to understand full-stack web development by building a 3-tier expense tracking application.

## Project Goal

Convert a simple Python CLI expense tracker into a full-stack web application with:
- **Backend API** (FastAPI)
- **Frontend** (Flask → later React)
- **Database** (SQLite with SQLAlchemy ORM)

## Architecture

```
Frontend (Flask/React) → Backend API (FastAPI) → Database (SQLite)
```
