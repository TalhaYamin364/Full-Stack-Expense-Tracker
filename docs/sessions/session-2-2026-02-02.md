## Key Learning Bridges Identified

**DBT → Backend APIs:**
- DBT models are like API endpoints (transform/serve data)
- Model dependencies = API request chains
- `ref()` in DBT = function calls between modules
- **Key Difference:** DBT = build-time, APIs = runtime

**SQL → SQLAlchemy ORM:**
- SQL skills transfer to understanding ORM queries
- ORM writes Python that becomes SQL
- Helps with query optimization
